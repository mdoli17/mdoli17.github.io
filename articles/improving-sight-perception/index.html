Introduction

In stealth gameplay, vision is more than a simple on/off switch. Binary detection often feels predictable - either the player is seen or completely invisible. To build tension and create more believable AI, I extended Unreal Engine’s perception system with a custom Vision Model Component.

This system introduces smooth vision cone tracking, a target weight scoring model, and progressive awareness buildup, all fully integrated into my AI framework.

Problem with Default Vision

Unreal’s built-in sight perception works, but it is limited:

  • Detection is instantaneous and binary
  • AI can snap from idle to chase with no buildup
  • Little room for “suspicion”

I wanted to move from robotic detection to gradual, math-driven awareness.

Vision Model Overview

The Vision Model Component calculates a weight</b> for each visible target and updates an Awareness Score over time. This enables states like:

  • Suspicious: Player is barely noticed.
  • Searching: AI saw “something” and investigates.
  • Detected: Player is fully itendified.

Smooth Cone Tracking

The vision cone is aligned with the AI’s head orientation rather than snapping directly the the player. This keeps perception grounded in animations and makes AI feel more lifelike.

Integration with AI Framework

The system ties into Unreal’s AI stack:

  • Vision Model Component: Broadcasts events for getting a clue, detecting or losing target
  • AI Controller: Updates handles vision model events and notifies State Tree using State Tree Events
  • State Tree: Handles high-level transitions like Neutral → Search → Hostile
  • Behavior Tree: Uses blackboard values to trigger search or chase tasks.

Gameplay Impact

The difference is noticeable:

  • AI hesitates before spotting, allowing tense near-misses.
  • Suspicion triggers search behaviors, not instant aggression.
  • Multiple clues (sound + weak sight) can combine into full detection.

This creates more dynamic, believable stealth encounters.

Closing

By extending Unreal’s perception with math-driven awareness, I made stealth encounters less binary and more immersive. This project shows how custom systems, math, and AI frameworks can combine to improve player experience in systemic gameplay.
